# Review Ratings Classifier — Video Production Brief

**Target:** 45 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

Use the real review-classification interface and only show predictions from a working configured Flask API. Explain that the ensemble uses review text and the SVM pipeline also uses a numeric rating. Label outputs as experimental model predictions, not business facts.

## Shot list

0–5s: title card. 5–14s: enter a sample review. 14–25s: compare ensemble and SVM input requirements. 25–34s: show actual JSON response and model label. 34–40s: explain TF-IDF and classifier pipeline. 40–45s: repo and experimental-use note.

## Voiceover draft

An NLP demo that routes review text through saved scikit-learn pipelines and returns an experimental sentiment label.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.
